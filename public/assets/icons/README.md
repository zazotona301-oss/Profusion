# أصول أيقونات عيادتي

ضع ملفات الصور المخصصة داخل هذا المجلد، ثم استخدم المسار العام التالي داخل JSX:

`/assets/icons/<اسم-الملف>`

| الملف | الاستخدام | المقاس الموصى به | الصيغة |
|---|---|---:|---|
| `clinic-mark.svg` | شعار العيادة والعلامة الرئيسية | 512×512 | SVG أو PNG |
| `patient-folder.svg` | ملفات المرضى | 128×128 | SVG أو PNG |
| `doctor-diagnosis.svg` | تشخيص الطبيب | 128×128 | SVG أو PNG |
| `lab-results.svg` | التحاليل والفحوصات | 128×128 | SVG أو PNG |
| `prescription.svg` | الروشتات والتقارير | 128×128 | SVG أو PNG |
| `appointment-calendar.svg` | المواعيد والحجوزات | 128×128 | SVG أو PNG |
| `invoice-billing.svg` | الحسابات الطبية | 128×128 | SVG أو PNG |
| `empty-records.svg` | حالة عدم وجود سجلات | 512×512 | SVG أو PNG |

## طريقة الاستخدام

```jsx
<img src="/assets/icons/doctor-diagnosis.svg" alt="تشخيص الطبيب" className="app-asset-icon" />
```

يفضل استخدام SVG للأيقونات لأنها واضحة على جميع أحجام الشاشات ولا تفقد جودتها. إذا استُخدمت PNG، احفظ نسخة شفافة واحتفظ بالمقاس الأصلي الموصى به.

## قواعد التسمية

استخدم أسماء إنجليزية صغيرة بصيغة `kebab-case`، ولا تغيّر المسار بعد ربطه بالواجهة. الملفات الموجودة هنا هي بدائل أولية قابلة للاستبدال بملفات العيادة النهائية مع الحفاظ على الاسم نفسه.
